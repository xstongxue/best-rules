# 项目背景
本项目使用 **PyQt5/6** 开发一个桌面应用，目标是提供一个跨平台的图形用户界面应用，涉及图形界面设计、事件处理和数据存储等功能。

# 编码标准
- 所有代码必须符合 **PEP 8** 编码规范。
- 使用 **snake_case** 命名变量和函数，类名使用 **PascalCase**。
- 代码中必须有适当的注释，尤其是 UI 逻辑和信号槽机制的部分，函数必须有 **docstring**。
- 避免过长的函数，确保每个函数的职责单一。

# 库和框架约束
- 必须使用 **PyQt5** 或 **PyQt6** 提供图形用户界面（GUI），不得使用其他 GUI 库。
- 使用 **Qt Designer** 创建 UI 文件，并通过 `pyuic5` 或 `pyuic6` 转换为 Python 代码。
- UI 组件与逻辑代码分离，所有 UI 代码应放在 `ui/` 目录下，功能代码放在 `src/` 目录下。
- 所有图形界面操作应遵循 **信号与槽**（Signal and Slot）机制，避免使用非标准的回调方式。
- 使用 **pytest** 进行单元测试，所有功能必须有测试覆盖。

# 文件结构
- 所有源代码文件应放在 `src/` 目录下。
- UI 文件通过 **Qt Designer** 创建，应存放在 `src/ui/` 目录下。
- 资源文件（如图标、图片等）应放在 `resources/` 目录下，并通过 `.qrc` 文件进行管理。
- 测试代码放在 `tests/` 目录下。

# 文档规范
- 每个模块的顶部应有描述模块功能的注释。
- 所有函数、方法和类必须有 **docstring**，包括功能描述、参数说明和返回值类型。
- 对于复杂的界面逻辑，必须写清楚如何通过 **信号与槽** 实现事件处理，特别是如何处理界面与后台逻辑的交互。

# 安全规范
- 绝不将 **API 密钥** 或 **敏感信息** 硬编码在代码中，所有敏感信息应存储在 `.env` 文件中。
- 使用 **Qt's QSslSocket** 模块进行加密通信，确保安全的数据传输。
- 确保所有输入数据的有效性，避免出现 **SQL 注入** 或其他注入攻击的风险。
